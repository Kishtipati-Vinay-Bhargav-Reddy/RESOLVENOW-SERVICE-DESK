# PS027 – Enterprise Issue Escalation & Service Desk Management System

## Project Description
ResolveNow Service Desk is an automated ticket management platform for logging customer grievances, assigning issues to specialized departments, tracking resolution lifecycles, providing real-time ticket updates, and sending automated progress alerts.

## Planned Technology Stack
- React
- Spring Boot microservices
- PostgreSQL
- JWT authentication
- Eureka Service Discovery
- Spring Cloud API Gateway

## Planned Microservices
- Complaint Service
- Assignment Service
- Notification Service
- Auth Service
